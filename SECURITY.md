# Security Policy

## Supported versions

This repository is documentation-focused. Security fixes apply to the latest `main` branch.

## Reporting a vulnerability

If you discover a security issue in **deployed site configuration**, CI, dependency supply chain, or example code that could harm readers:

1. **Do not** open a public issue with exploit details
2. Email the maintainer via the GitHub profile contact for [OmidJavaherii](https://github.com/OmidJavaherii), or use GitHub Security Advisories on this repository if enabled
3. Include reproduction steps, impact, and suggested remediation when possible

We will acknowledge reports as quickly as practical and coordinate disclosure.

## Documentation content

Corrections to security *explanations* (XSS, CSRF, CSP, etc.) should be filed as normal issues/PRs unless they reveal an active vulnerability in a live system.
